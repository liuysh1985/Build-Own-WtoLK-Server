# Configuration Part
Target: Support 10 real players and 50+ bots


## Folder Structures
Default Runtime Folder: `$HOME/WotLK/runtime`

|File/Folder|Usage|
|-|--|
|conf/|All configuration files, including module part|
|db/|Database directory, used by mysql container|
|data/|Maps data, extracted from client|
|logs/|Server logs|


## Configuration
### AC env
Path: `$RUNTIME_DIR/conf/env.ac`
